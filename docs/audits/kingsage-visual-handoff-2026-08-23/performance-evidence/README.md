# performance-evidence/

**This folder is empty, and that is the true state of the project.**

No performance measurement of any kind has ever been taken for this project — on
desktop, on a phone, or in Studio. There is no FPS log, no microprofile capture,
no memory reading and no frame-time data.

The oldest outstanding task in the project is **drill C5, the 200-troop phone
measurement**, written on 2026-08-21 and never run. `BattleConfig.MAX_SOLDIERS =
200` is a starting guess with adaptive culling, not a measured budget.
